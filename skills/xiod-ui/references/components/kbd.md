# Kbd

```tsx
import { Kbd, KbdGroup } from "xiod-ui/kbd";
```

## Kbd

Renders a `<kbd>` and takes its props. Pass `render` to render a different element.

## KbdGroup

Renders a `<kbd>` and takes its props. Pass `render` to render a different element.

Required props are bold. Full docs: https://ui.xiod.dev/docs
